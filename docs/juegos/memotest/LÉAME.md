# 🧠 Memotest

Juego de memoria (Memotest) desarrollado con HTML, CSS y JavaScript vanilla.

## 🎮 Cómo jugar

1. Abrí `index.html` en tu navegador.
2. Hacé clic en las cartas para darlas vuelta.
3. Encontrá todos los pares en la menor cantidad de intentos y tiempo posible.

## 🕹️ Características

- 4 niveles de dificultad (Fácil, Medio, Difícil, Experto)
- Contador de movimientos
- Temporizador
- Sistema de puntaje
- Diseño responsive
- Tests unitarios incluidos

## 🧪 Ejecutar tests

Abrí `test.html` en el navegador o corré los tests desde la consola.

## 🛠️ Tecnologías

- HTML5
- CSS3
- JavaScript (ES6+)
