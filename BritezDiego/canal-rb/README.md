# Primicia — Un día en Canal RB

Juego 2D de navegador sobre el trabajo en un medio audiovisual (prueba piloto, Fase 1).
Todos los datos y personajes son inventados, hechos para la facultad.

## Cómo abrirlo

En una terminal, dentro de esta carpeta:

```
python3 -m http.server 8000
```

Después abrí `http://localhost:8000` (en Codespaces: pestaña **Puertos**, puerto 8000).

## Archivos

- `index.html`: pantallas e ilustraciones
- `estilos.css`: colores y animaciones
- `main.js`: lógica del juego (menú, personaje, oficina, estrellas, pausa y guardado)

## Cómo se juega

Flechas o WASD (o tocar/hacer clic) para moverte; entrá por las puertas en orden: Redacción, Producción y Al Aire. P o Esc para pausar. El avance se guarda solo en el navegador.

## Estado

Fase 1: menú, elección de periodista, oficina y recorrido. Las tres tareas son por ahora de prueba.
