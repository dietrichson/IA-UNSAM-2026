# Reto: Tuneá a tu Qwen
## Hecho por:
Sofia del Pilar Pereyra, Agustina Franconieri, Rosario Degliuomini

## Sobre el Juego:
El juego que desarrollamos se llama “Reto: Tuneá a Qwen” y consiste en una trivia interactiva que busca enseñar de manera sencilla cómo darle instrucciones a una inteligencia artificial para obtener mejores respuestas. El juego tiene diez preguntas de opción múltiple, con cuatro respuestas posibles y un tiempo límite de 20 segundos para cada una. Los participantes suman puntos cuando responden correctamente, y cuanto más rápido lo hacen, mayor es el puntaje. Además, pueden obtener puntos extra si acumulan varios aciertos seguidos. Después de cada pregunta aparece una explicación para que el jugador pueda aprender del resultado. Al finalizar, se muestra el puntaje total, la cantidad de respuestas correctas y el nivel alcanzado. Para desarrollar el juego utilizamos *HTML, CSS y JavaScript. HTML se encarga de organizar las pantallas, las preguntas y los botones; CSS permite diseñar la apariencia visual, incluyendo los colores y las animaciones; y JavaScript controla el funcionamiento del juego, como el tiempo, las respuestas correctas y el sistema de puntuación. En cuanto al contenido, las preguntas abordan conceptos relacionados con la inteligencia artificial, como los prompts, la importancia de dar instrucciones claras, las alucinaciones y la diferencia entre modificar las instrucciones y reentrenar un modelo. Es importante aclarar que el juego no utiliza inteligencia artificial en tiempo real, sino que funciona con preguntas y respuestas previamente programadas. 
Nuestro objetivo fue crear una herramienta educativa y entretenida que permita comprender mejor cómo interactuar con una inteligencia artificial y cuáles son algunas de sus limitaciones.
