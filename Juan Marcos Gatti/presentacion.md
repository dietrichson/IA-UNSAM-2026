## Proyecto Atenea

Para este trabajo desarrollé **Atenea**, una asistente de inteligencia artificial personalizada orientada principalmente al ámbito académico y tecnológico.

El proyecto busca explorar cómo un **system prompt** puede establecer la identidad, personalidad, objetivos, reglas y forma de comunicación de un modelo de lenguaje.

Atenea se ejecuta mediante Ollama utilizando el modelo **qwen2.5:3b** y se complementa con un sistema RAG que permite recuperar información desde documentos locales.

El objetivo del proyecto es comprender de manera práctica cómo se pueden personalizar modelos de lenguaje y combinar instrucciones, modelos locales y recuperación de información para construir una asistente especializada.
