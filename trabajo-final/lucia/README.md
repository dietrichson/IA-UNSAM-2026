# Ta-Te-Ti con Comentarista Deportivo

Aplicación web interactiva de Ta-Te-Ti (Tic-Tac-Toe) desarrollada para el Seminario de Inteligencia Artificial en la UNSAM (2026). El proyecto incorpora un sistema de narración dinámica estilo comentarista deportivo que reacciona en tiempo real a las jugadas del usuario.

## Integrantes
* Lucía Ruiz Serman

## Descripción general
El proyecto combina la lógica tradicional del juego de Ta-Te-Ti con un flujo asistido por IA e interfaces web dinámicas. Cuenta con un diseño visual personalizado y comentarios en texto que simulan una transmisión deportiva en vivo según el desarrollo de la partida.

## Cómo ejecutar el proyecto
1. Clonar el repositorio o navegar dentro de la carpeta personal del proyecto (`trabajo-final/lucia/`).
2. Abrir el archivo principal de la interfaz web en cualquier navegador web moderno (haciendo doble clic o utilizando un servidor local como Live Server en VS Code).
3. Interactuar con el tablero para iniciar la partida y visualizar los comentarios en tiempo real.
